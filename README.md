# MAS ETH DFAB year 2026-27

Welcome to the official repository for the Master of Advanced Studies in Architecture and Digital Fabrication (MAS DFAB) 2026-2027! 🚀

Here you'll find all the resources, code, and documentation you need for a successful year of learning, making, and collaborating.

## Start Your Journey
- Explore the course materials
- Share your ideas and code
- Build something amazing together!

## Repository Structure

| Folder | Content |
| --- | --- |
| [00_Introductions](00_Introductions/) | Setup, installation party and first steps |

Further module folders are added over the course of the year. Each module typically contains:
- `*.gh` / `*.ghx` — Grasshopper definitions used in the tutorials
- `src/` or `scripts/` — Python modules imported by the Grasshopper scripts
- `data/` — inputs and exported results (JSON, Rhino files)
- `docker/` — `docker-compose` files for the ROS / robot backends
